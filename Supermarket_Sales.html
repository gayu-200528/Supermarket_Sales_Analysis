Supermarket Sales Analysis¶

Project Domain:- Supermarket Sales Analytics| Data Analysis | Business Intelligence¶

Project Objective:¶

  • The objective of this project is to analyze supermarket grocery sales data using Python to understand sales and profit patterns across product categories, sub-categories, cities, and regions. The project includes data cleaning, preprocessing, exploratory data analysis (EDA), visualizations, and business insight generation.

Skills¶

  1. Python
  2. Pandas
  3. Numpy
  4. Data Cleaning & Preprocessing
  5. Missing Value Treatment.
  6. Exploratory Data Analysis(EDA)
  7. Data Visulization (Matplotlib & Seaborn)
  8. Business Insight Generation

Dataset Description¶

  • Dataset Name: Supermart Grocery Sales Dataset
  • Records: 1000
  • Features: 17
  • Target Variables: Sales and Profit

Key Attributes:¶

  • Order Details: Order ID, Order Date, Customer Name
  • Location Information: City, State, Region
  • Product Details: Category, Sub-Category
  • Sales Performance: Sales, Discount, Profit

sales_by_product.plot(kind="bar", figsize=(10, 5))

plt.title("Total Sales by Product Line")
plt.xlabel("Product Line")
plt.ylabel("Total Sales")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
